Stock Analysis with Excel

Overview

This project provides a comprehensive stock analysis tool built using Microsoft Excel. 
It utilizes data sourced directly from the U.S. Securities and Exchange Commission (SEC) and applies regression techniques to forecast future stock prices. 
The tool is designed to help investors and analysts gain insights into stock trends and make informed investment decisions.

Features

SEC Data Integration:
Data is pulled from SEC filings, ensuring reliability and transparency.

Stock Analysis:
Key metrics and trends are calculated and visualized, including price movements, volume analysis, and financial ratios.

Forecasting:
Future stock prices are predicted using regression models, providing a data-driven outlook.

User-Friendly Excel Design:
Easy-to-navigate interface with pre-built formulas, charts, and instructions for users of all skill levels.

Requirements

Microsoft Excel (Any).

Data Source: SEC filing data in CSV or Excel format.

How to Use

Data Input:
Import the SEC data into the designated Excel sheet.

Execute Analysis:
Use pre-configured formulas to generate stock insights.

Forecast:
Review regression-based stock price forecasts on the designated dashboard.
Stock price is pulled using python, and exported as a CV file. The data is then copied and pasted into the Excel.

Visualize:
Explore trends and projections using built-in charts.

Regression Methodology

The forecasting component uses linear regression, with the option to adjust input variables such as historical stock prices, market trends, and financial ratios. This ensures customizable and accurate projections.
